# Cuban Missile Crisis 1962

This is the design placeholder for the first playable vertical slice. The
current implementation is hard-wired in Python at
`src/crisis_room/scenario/schema.py`.

## Playable Frame

- Player faction: U.S. EXCOMM.
- Main rival: Soviet Presidium.
- Additional crisis actors: Cuban Revolutionary Government, NATO Allies, and
  the International Community.
- Core dilemma: combine public pressure, naval quarantine, reconnaissance, and
  private bargaining without triggering local military escalation.
- Main off-ramps: private Kremlin backchannel, non-invasion pledge, and a
  deniable Jupiter missile understanding.
- Main chaos sources: U-2/reconnaissance risk, Cuban air defense initiative,
  naval misreads, leaks, allied anxiety, and public panic.
