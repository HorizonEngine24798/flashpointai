# Cuban Missile Crisis 1962

The first playable scenario. Its content is split across the
`src/crisis_room/scenario/cuba_*.py` modules and assembled by
`build_cuban_missile_crisis_1962_scenario()` in `cuba.py`.

## Playable Frame

- Player faction: U.S. EXCOMM.
- Main rival: Soviet Presidium.
- Additional actors: Cuban Revolutionary Government, NATO Allies, and the
  International Community.
- Core dilemma: combine public pressure, naval quarantine, reconnaissance, and
  private bargaining without triggering local military escalation.
- Main off-ramps: a private Kremlin backchannel, a non-invasion pledge, and a
  deniable Jupiter missile understanding.
- Main chaos sources: reconnaissance risk, Cuban air-defense initiative, naval
  misreads, leaks, allied anxiety, and public panic.
